# Col tile atlas — September 5, 2026

A certificate-backed catalog for the one-sided/weighted tiling proof project.

## Main results

- Complete 5x4 classification: **175 exact-zero permission patterns out of 1,048,576**, generated by 14 minimal White supports (four reflection orbits).
- None of the safe 5x4 patterns can be joined to another safe 5x4 pattern along a straight full-side seam. This is a restricted construction-class no-go theorem, not a statement about all tilings.
- The alternating 5x4 extrusion has **exact value +3/4**. Its ten odd-parity Blue openings leave **-1**; cell 8 leaves **+1/2**; the other nine leave nonnumerical next-player-winning games.
- Twenty-one complete shape catalogs: **3,598,668 permission assignments**, **49 primitive zero supports**, **1,682 safe full-Blue roots**.
- **152,473 partial-state upper-bound lemmas** extracted from checked strategy checkpoints.
- Constructive infinite families E_(4k), J_n in residues 0/1/2 modulo 4, and even-by-even checkerboard-support tiles.

Read `CATALOG.md` for patterns and `THEOREMS.md` for precise statements/proofs.

## Verify without searching

Requires Python 3; uses only its standard library.

```bash
python3 verify.py
python3 verify_numeric.py
python3 test_constructions.py
python3 verify_index.py
python3 test_corruption.py
```

`verify.py` checks every finite local strategy and the complete monotone-lattice cover on all 21 shapes. `verify_numeric.py` checks two-sided comparisons against exact dyadic numbers and separate outcome-N witnesses. `test_constructions.py` checks 176 concrete embeddings of the parametric proofs, including all 40 single-Blue openings on 5x8. `test_corruption.py` checks that malformed certificates are rejected.

## Files for the engine

- `atlas.json`: primitive zero tiles, four ports, exact masks, proof references, and per-shape coverage.
- `certified_partial_tiles.jsonl.gz`: independently certified partial tiles, each tagged **upper_bound = 0** with its source certificate/node. Do not import these all as zero games.
- `data/numeric_manifest.json`: exact dyadic and explicitly nonnumerical outcome claims.
- `data/fullHxW_frontier.json`: safe masks and the two irredundant frontiers for each shape.
- `certificates/`: finite response DAGs; hashes are in `SHA256SUMS`.

`b` denotes Blue-only permission, NOT a placed Blue stone. Match roles and masks before using any tile. Boundary compatibility and full coverage remain compulsory. Numerical equality is interchangeable in genuine disjunctive sums; the one-sided cut only supplies an inequality for the physical board.

## Regeneration

```bash
bash regenerate.sh
```

This builds the included C++17 generators, regenerates the finite certificates, reruns the independent checks, and rebuilds the atlas index. It does not launch an unbounded large-board solve. The current atlas itself can be verified without a compiler or network access.

Discovery CSVs are compressed under `discovery/`. In those scans, result 0 means first actor loses, 1 means first actor wins, and 2 means the node budget was exhausted. Unknown rows must never be treated as either win or loss. The 3x8, 4x6, and 5x6 exploratory scans do not support complete catalogs.
